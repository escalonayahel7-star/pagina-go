## 2. "El camino" · Capítulo 1965 (reel narrado, ~48 s, 100 palabras)

```
San Andrés Lagunas, Oaxaca. / Mil novecientos sesenta y cinco. //
Un muchacho llega a la Ciudad de México / sin nada. //
Duerme bajo los puentes del Centro Histórico. //
Pero en los aparadores de las sastrerías del barrio / ve algo que no va a olvidar. //
Un año después, / un maestro alemán lo toma como aprendiz. / Seis años de *disciplina*. //
A los diecinueve, / ya es maestro sastre. //
Su nombre: / Gilberto Ortíz Osorio. //
Su filosofía cabía en una frase: / la honestidad tiene un premio, / el éxito. //
Hoy, sus hijos la llevamos en cada puntada. //
Gilberto Ortíz e Hijos. / Legado desde mil novecientos sesenta y cinco.
```

cierre con el logo. Texto en pantalla: `1965`, `1966`, `MAESTRO SASTRE A LOS 19`, la frase en cursiva dorada.
