# Efectos de sonido: origen y licencia

Todos los efectos de esta carpeta son **originales**: se sintetizaron por código con
`scripts/generate-sfx.py` (osciladores, ruido filtrado y reverb). No contienen muestras
de terceros, así que no hay licencias externas que cumplir. Se pueden usar comercialmente.

| Archivo | Qué es |
|---|---|
| shimmer.wav / shimmer-final.wav | Destello brillante (logo y botón) |
| tijeras.wav | Un corte de tijera sobre tela |
| whoosh.wav / swipe.wav | Paso de aire suave / entrada del celular |
| impacto.wav | Golpe grave discreto (TOP 3) |
| tela.wav · hilo.wav · cinta-metrica.wav | Fotos del oficio |
| tic.wav | Aparición de cada casa de telas |
| scroll.wav | Roce mientras se desplaza la página |
| clic.wav | Clic del botón "Reservar mi cita" |

Si más adelante quieres cambiarlos por grabaciones reales (Pixabay, Mixkit, Freesound CC0),
pon el archivo aquí, cambia el nombre en `SFX` de `src/config.ts` y anota la fuente y la
licencia en esta tabla.
